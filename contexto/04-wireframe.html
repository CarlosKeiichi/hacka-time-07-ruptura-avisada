Como usar este rascunho

Abra no celular e no computador — foi desenhado para os dois. As duas telas são o escopo inteiro que o card permite: 1 fluxo principal + 1 tela de resultado. Se aparecer uma terceira tela na conversa, ela vai para o contexto/backlog.md.

A Voz do Cliente valida antes de qualquer código. Imprima, entregue uma caneta e peça para riscar o que não faz sentido. O que ela riscar, muda.
